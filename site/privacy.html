Privacy policy

Last updated: November 15, 2026

This policy covers "uploader", a personal tool that uploads its owner's own videos to its owner's own YouTube channel. The tool is used only by its owner. It has no other users and no sign-up.

Information the tool accesses

The tool uses YouTube API Services with a single permission: uploading videos (https://www.googleapis.com/auth/youtube.upload). With it, the tool sends a video file, a title, a description and tags to the owner's YouTube channel.

The tool does not read the owner's Google account profile, email, contacts, watch history, comments or any other YouTube data. It does not access anyone else's account.

Information the tool stores

To upload without asking for sign-in every day, the tool keeps an OAuth client ID, client secret and refresh token. They are stored as encrypted secrets in the owner's private GitHub repository and are used only to request upload access from Google. The tool keeps a list of the videos it has uploaded (title, upload date and video URL). It stores no other personal data.

Sharing

The tool does not sell, share or transfer any information to third parties. The only data that leaves the tool is the video and its text, which are sent to YouTube for publication on the owner's channel.

Limited use

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google terms

The tool uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time on the Google account permissions page. Deleting the stored secrets from the GitHub repository removes everything the tool holds. Uploaded videos can be deleted in YouTube Studio.

Changes

If this policy changes, the new version will be posted on this page with a new date.

Contact

Questions about this policy can be sent through the issue tracker.

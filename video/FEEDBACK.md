# もらった指摘の記録

チャンネルの持ち主が動画を見て付けた評価と指摘を、型ごとにまとめたものです。
新しい指摘をもらったら、その型の行に足します。ここから読み取れる決まりは [`QUALITY.md`](QUALITY.md) にあります。

評価の言葉は、もらった言葉をそのまま使っています（素晴らしい ＞ 合格・良い ＞ 及第点 ＞ 普通 ＞ やや悪い ＞ 悪い）。

## 投稿してよいと言われた型

| 型 | 最後の評価 | これまでの指摘と、直したこと |
|---|---|---|
| `towers` | **素晴らしい** | 最初は「重力を無くした方が良い」「数値がこまかい、0 を使って見やすく」→ 重力なし・丸い数字にした |
| `colorwar` | **素晴らしい**（条件を変えた版） | 最初の版は「増え方に規則性が無い」「赤が勝つのは当たり前」で削除。「初期の数は多いが増殖力が少ない、またはその逆」という提案を受けて、条件の違う 4 色にした |
| `arms` | **合格。これを基準にする** | 「潰れてない時も増えてる」「真ん中から急に出現している」（2 回）→ 挟まれた時だけ、その場で割れるようにした。「右上と左下のアームが機能していない」→ 回る向きごとに形を鏡写しにした |
| `gear` | 良い | 最初は「悪い。分裂のタイミングが意味不明」「動きが遅くて爽快感が無い」→ 2 本のアームに挟まれた時だけ割れるようにし、速くした。投稿後、一番伸びた |
| `walls` | 良い | 「決着が早すぎ」「完全に道を塞がない」「壁の数は N 個まで」→ 直した。「ゴールまで何マスかの表示は、結果が分かるので不要」→ 消した。「残り何枚置けるかは分かりやすくて良い」 |
| `rings` | 良い | 「内容は良い、音が心地よくない」→ 音を和音の並びにした。「意外性は無いが、ボーッと見る分には良い」 |
| `multiply` | 良い（この形式の限界） | 「連鎖的な爆発が欲しい」「音が単調で雑」「最後がよく分からない」→ 直した。「今後は他のタイプも試して」 |
| `battle` | 単調だけど良い | |
| `bricks` | 残すのはあり | 「同条件で始まってるからあみだくじと変わらない。ただ理不尽感が無い」 |
| `glass` | 及第点 | 「増殖した玉が直接ガラスに当たっていて意味が不明」「急に割れる」「玉が途中で消えている」「変な線がある」→ 砲台が撃つ形に作り直した。「×2 がほとんど使われていない」→ ×2 をまん中に移した。「もう少し活かせる配置があると思う」 |
| `hammer` | 及第点 | 「ハンマーの動きが不規則すぎる」→ 上・中・下の順に交互に叩くようにした |
| `cam` | 及第点 | 「爽快感が無い」「増えるのが確定している」「潰れているのに増えないものがある」「爆発力に欠ける」→ 回転をだんだん速くした。まだ改善の余地あり |
| `music` | 及第点 | 「これは何語？」「不協和音、メロディーがおかしい」「壁を貫通している」→ 直した。「繰り返しで単調、反射も単調」「壁を斜めに配置し過ぎ」「当たって無いのに音が鳴るのが違和感」→ 伴奏をやめ、縦横の壁だけにした。「2D なら壁反射の方針を追求」 |
| `chime` | 及第点 | 「玉が 2 個になったり、もう少し動きをつけるのが理想」→ `chime2` を試作中 |
| `marble`（3D） | 良い | 2D 版は「コースが単調。3D でピタゴラスイッチみたいに」→ 3D で作り直した。「上の順位と見た目の順位がズレてる」→ 直した。自動投稿に入れるかは検討中 |

## 全部の型に言われたこと

- 「ボールの軌跡が残り続けるのが不必要。最後に背景が汚く見える」
- 「同条件で始めるのではなく、初期条件を変えるのはどう？」
- 「数値は有効数字 3 桁くらいのイメージ」
- 「動画や音は、ほかの動画やサイトを調べて参考にして」
- 「arms は合格。これを基準として様々なものを作成していって。arm にこだわらなくてもよい」
- 「今良い動画を作ることもそうだが、今後良い動画を作るための環境作りも進めて」

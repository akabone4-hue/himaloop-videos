# 物理シミュレーション動画の生成

縦型（1080x1920・60fps）のショート動画を、コードだけで作ります。映像も音もこのフォルダ内で生成するので、他人の映像・音源・素材は一切使っていません。

## 種類

| 名前 | 内容 |
|---|---|
| `grow` | 跳ねるたびにボールが大きくなる。壁に当たるたびに曲が 1 音ずつ進む |
| `rings` | 回転する 10 重のリングのすき間から脱出する |
| `multiply` | リングから脱出するたびにボールが 2 個増える。220 個になるとリングが割れ、全部のボールが 3 個ずつに弾けて飛び散る |
| `colorwar` | 4 色の陣取り合戦。色ごとに条件が違う（9 個で増えない／5 個で 7 秒ごとに +1／2 個で 4 秒ごとに +1／1 個で 8.5 秒ごとに 2 倍）。どの色がどの条件かは毎回入れ替わる |
| `battle` | HP 制のボール 6 個のバトル。枠がだんだん狭くなる |
| `marble` | 3D。8 色のビー玉が壁掛けコースを下るレース。ギミック（ジグザグ坂・釘の板・回る羽根・じょうご・階段・振り子ハンマー・水車）の並びと配置は毎回変わる |
| `music` | 2D の壁反射。ボールが斜めにまっすぐ進み、縦か横の板で跳ね返るたびに 1 音鳴る。進む角度は動画ごとに少し変わる。当たった板は光って少し引っ込む。伴奏は鳴らさない |
| `hammer` | arms の仲間。左右の壁を 2 本のピストンが 上・中・下 の順に交互に叩く（叩くたびに低い音）。ピストンと壁にはさまれたボールが 2 つに割れる |
| `cam` | arms の仲間。円の中心から伸びた 3 本の腕の先で、ローラーが壁すれすれを回る。ローラーと壁にはさまれたボールが 2 つに割れる。回転がだんだん速くなり、終盤に一気に増える |
| `towers` | 条件の違う 3 つの塔（少数で階ごとに 3 倍／階ごとに 2 倍／最初から大勢で階ごとに一定数ずつ増える）。10 階を最初に壊した塔が勝ち。数値は切りのいい数だけを使い、ほぼ同時に終わる組み合わせをあらかじめ探して入れてある |
| `chime` | 3D。色つきの鉄琴の上をボールが弧を描いて跳ね、着地するたびに 1 音鳴る（次の音までが長いほど高く跳ぶ）。経路は `sims_course.arc_layout` が決め、絵は `blender_chime.py` が描く |
| `towers2` | towers の別バージョン。階ごとに 2 倍／毎秒決まった数ずつ増える／最初から大勢で増えない、の 3 つ |
| `cannons` | towers の兄弟。3 本のレーンで砲台が上の壁を撃つ。撃つ速さが倍々になる 1 門／一定時間ごとに 1 門ずつ増える／最初から何門もある、の 3 つ |
| `hexarms` | arms の別バージョン。六角形の角 3 つでアームが回る |
| `beams` | 円の中で 2 本の光線が逆向きに回る。緑に触れたボールは 2 つに割れ、赤に触れたボールは消える。300 個で弾ける |
| `survive` | 6 色のボールがローラーから逃げる生き残り戦。潰されるたびにライフが 1 減り、最後に残った 1 個が勝ち |
| `smash` | survive のピストン版 |
| `survive2` | survive の別バージョン。小（ライフ 3）・中（ライフ 4）・大（ライフ 15）が 2 個ずつ。大きいほど挟まれやすい。ライフは試算で勝率をそろえた値 |
| `gear2` | gear の別バージョン。アームが 4 本（2 本ずつ逆向き）で、2,000 個まで増える |
| `bricks2` | bricks の別バージョン。6 ダメージ 1 個／3 ダメージ 2 個／1 ダメージ 6 個、の 3 レーン |
| `bomb` | 爆弾まわし。爆弾は触れた相手に移り、導火線が尽きたとき持っていた色が脱落。爆弾は一番近いボールへ飛ぶ。最後の 1 個が勝ち |
| `plinko` | 600 個のボールを釘の板に落とす。13 個の仕切りに山ができ、色の波が 1 列ずつ数えたあと、底が開いて流れ落ちる |
| `chain` | 折り返す帯に並んだ 1,000 個の点。上から落ちた 1 個のボールをきっかけに、弾けた点の火花がとなりの点を弾けさせ、連鎖が帯をたどって最後に爆弾へ届く |
| `merge` | 左右に動く口から数字の付いたボールが落ちる。同じ数字どうしが触れるとまとまって倍になり、1024 ができたら全部弾ける |
| `fillwave` | 形（ハート・六角形・円・ひし形）の中でボールが増え続け、いっぱいになると色の波が走って虹色に並び、最後に弾ける |
| `blackhole` | 8 色のボールが、育っていくブラックホールから逃げる。触れたら脱落。最後に残った 1 個が勝ち |
| `rps` | グー・チョキ・パーの駒が、勝てる相手を追い、負ける相手から逃げる。触れた相手を仲間に変え、1 種類になったら終わり |
| `faces` | 3D。同じ布を面の数だけ変えて（16 → 4096 面）順に球の上へ落とす |
| `weapon` | 武器を持ったボールの 1 対 1。当てるたびに武器が強くなる |
| `bricks` | ブロックを掘り進むレース。最初に掘り抜いた色が勝ち |
| `fill` | 1 個のボールが 2 個に分かれ続け、扇形が広がって円を埋め尽くすと弾ける |
| `gear` | 円の中心の歯車に半円のアームが 2 本付いて逆向きに回る。2 本のアームに両側からはさまれて潰されたボールが、その場で 2 つに割れる |
| `arms` | 四角い箱の四隅で C 字のアームが回る。アームと壁に両側からはさまれて潰されたボールが、その場で 2 つに割れる。壁の外へ押し出されかけた球は、その場で壁の内側へ戻す |
| `glass` | 右の砲台（いつも同じ場所）がガラスを撃つ。当たったボールは消えてガラスが欠ける。外れた弾や弱い弾はくぼみに落ち、底の倍率ぶん増えて撃ち直される。倍率は真ん中が x2、外側ほど入りにくく x3・x4・x10 |
| `walls` | 4 色のボールが王冠を目指す盤上ゲーム。自分の番に「進む」か「壁を置く」。壁は 1 色 6 枚までで残り枚数を表示する。道を完全にふさぐ置き方はできない。王冠までの歩数は出さない（結果が読めてしまうため） |
| `rays` | 鏡の器の中で光線が反射する。1 本から 2048 本まで倍々に増え、光の模様になる |

曲は著作権の切れたクラシックと童謡（歓喜の歌、エリーゼのために、きらきら星、トルコ行進曲、山の魔王の宮殿にて）を、自前の合成音で鳴らしています。

## 作り方

GitHub 上で作る場合は、Actions タブの「Make Videos」を Run workflow で実行します。終わったら実行結果ページ下部の Artifacts から zip をダウンロードします。

PC で作る場合（Python と ffmpeg が必要）:

```
pip install -r video/requirements.txt
python video/make.py list                  # 種類の一覧
python video/make.py weapon                # 1 本作る
python video/make.py all --count 2         # 全種類を 2 本ずつ
python video/make.py rings --preview       # 低画質で手早く確認
```

`video/out/` に、動画（mp4）と投稿用テキスト（YouTube のタイトルと説明文、日本語版、TikTok の説明欄）が同じ名前で出ます。

乱数シードが違えば展開も結果も変わります。脱出やバトルのように長さが決まらない種類は、先に物理だけを高速で回して、ちょうどよい長さになるシードを自動で探してから書き出します。

## 自動投稿

`.github/workflows/post-video.yml` が毎日 1 本、動画を作って YouTube に投稿します。認証情報を登録するまでは何もしません。登録の手順は [`POSTING.md`](POSTING.md) の「YouTube の自動投稿を有効にする手順」にあります。

投稿の準備と各サービスの条件は [`POSTING.md`](POSTING.md) にまとめています。

## 3D の型（marble / faces）

作り方のくわしいメモ（速さの実測、詰まりの直し方、つまずいた点、ギミックや新しい型の足し方）は
[KNOWHOW_3D.md](KNOWHOW_3D.md) にあります。

絵を Blender（3D 制作ソフト。Python から使えるモジュール `bpy`）で描く型です。ほかの型と違う点：

- 追加のインストールが必要: `pip install -r video/requirements-3d.txt`（400MB 以上。Python 3.13 用）
- 書き出しが遅い: 4 コアのマシンで 1 コマ約 4 秒。30 秒の動画で 1 時間ほど（`--preview` なら 6 分ほど）
- `python video/make.py all` には含まれない。`python video/make.py marble --seed 5` のように名前で指定する
- 絵だけを確かめたいときは `python video/blender_marble.py --seed 5 --out DIR --quality preview --step 10`
  （10 コマおきに描く）。`--quality none` なら物理計算だけを回して、コースの並びと着順を表示する
- コースのどこかにビー玉が引っかかったら、そのコースは捨てて自動で作り直す

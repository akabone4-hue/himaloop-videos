# これから作るものの控え

思いついた型・調べて見つけた形式・直したい点を、忘れないように置いておく場所です。
作ったら [`FEEDBACK.md`](FEEDBACK.md) の「まだ見てもらっていない型」へ移します。

## 新しい型の候補

| 候補 | 中身 | 元 | メモ |
|---|---|---|---|
| 勝ち抜きトーナメント | 8 個が 1 対 1 で勝ち上がる | 伸びている形式の調査 | `weapon`（1 対 1）を 3 回戦つなぐと 45 秒を超える。1 戦を短くする工夫が要る |
| 迷路のゴール競争 | 条件の違うボールが迷路を抜ける | 同上 | 2D の marble は「コースが単調」と言われた。ギミックを入れること |
| ゲートを通ると増える | ×2・+10 などの門をくぐるたびに増える | 同上 | `multiply` は「この形式の限界」と言われている。門に当たる理由を物理で見せられるなら |
| 綱引き | 両側から撃ち合って、境目の線を押し合う | 同上 | `cannons` の部品が使える |
| 柔らかさの比較（0〜100% SOFT） | 柔らかさの違う玉を同じ仕掛けに通す | 参考動画 | 3D の布に「内側の圧力」を足す方法が有力（`KNOWHOW_3D.md`） |
| 氷を切る | 刃が氷を細かく切っていく | 参考動画 | 数万個の破片は物理では回せない。粒として見せる |

## 既存の型で直したい点

| 型 | 直したい点 |
|---|---|
| `chime2` | 鍵盤の見た目を「音の高さだけで決まる」ように直した（低画質の試作まで）。持ち主の返事待ち。速い曲では跳ねる高さが控えめ |
| `bricks2` | レーンが 3 本なので左右に余白がある。レーンを広げるには、大きさ・速さ・重力をまとめて同じ倍率にする（釣り合いが変わらない） |
| `bomb` / `blackhole` | 全員同じ条件のまま合格した。大きさや速さを変える版は、急がない |
| `gear`・`hammer`・`cam`・`hexarms`・`beams` | 色が「割れた瞬間の時刻」で決まる（違う色の玉が同時に割れると同じ色になる）。`gear2` は「潰された回数」に直して合格した。広げるかは持ち主に確認 |
| `cam` | 「爽快感が無い」「爆発力に欠ける」と言われたまま |
| `glass` | 「もう少し活かせる配置がある」と言われたまま |
| `faces`（3D の布） | 布がすぐ滑り落ちて、何も映らない時間が長い |
| `towers` 系 | ファイルが 60MB 前後。粒の数か描き方を見直す |
| 全部 | 出だしの 1 秒。1 個だけで始まる型は、最初の出来事までが遅い |

## 調べて分かったこと

- 「輪から脱出」「跳ねるたびに音」は 2022〜2024 年からの定番で、数が多い。同じ形をそのまま増やさない。
- 「形を埋め尽くす」短い動画は 1 本 10 万回前後が目安という集計があった（`fillwave` がこれ）。
- 自分のチャンネルでは「挟まれて潰されると増える」（`gear`）が飛び抜けて伸びた。
- 2026-11-23 の評価: 決まりが一目で分かり決着へ進む型は合格、眺めるだけの型（連鎖・埋め尽くし）は低評価。
  生き残り戦は、爆弾・ブラックホールは合格、「潰されるとライフが減る」は「面白くないかも」。

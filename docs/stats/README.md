## 見方

- **平均視聴率**: 動画の長さに対して平均で何 % まで見られたか。ショートでは 100% を超えると繰り返し見られている
- **再生数**はほぼリアルタイム。平均視聴率などは YouTube 側の集計に 1〜3 日かかるため、新しい動画は「—」になる
